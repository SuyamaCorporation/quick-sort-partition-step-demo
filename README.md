# クイックソート パーティション ステップ デモ

クイックソートのピボット選択と分割過程を棒グラフアニメーションで可視化し、比較・スワップ回数をカウントする教育ツール。

## 機能
- 配列サイズスライダー（5-30個）
- ランダム生成・逆順・昇順の初期配列選択
- 1ステップ実行ボタンと自動実行（停止可）ボタン
- ピボットを赤・比較対象を黄・確定済みを緑でハイライト
- 比較回数・スワップ回数カウンター
- ステップログ表示（スクロール対応）

## 技術
- Vanilla JS + Tailwind CSS CDN
- 全ステップ事前生成（buildSteps）によるステップバック対応設計
- CSS flexbox 棒グラフ（高さ = 数値比例）
